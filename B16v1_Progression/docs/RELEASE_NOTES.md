# Release notes

`B16v1_Progression_v1` packages the frozen formal Progression path: real pre query image history, relative time, 16 dimensional Progression condition, B14CPFM/B14Hooks, and SD1.5 with medical LoRA. Report condition, structure, pathology, and texture are disabled.

Three minimal custom checkpoints are included. The medical LoRA and SD1.5 base remain external. The public package has no original clinical data, patient list, report text, or generated patient images. Checkpoint loads and synthetic forward parity passed. A complete SD1.5 image generation run is not part of this package validation.
