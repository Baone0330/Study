# Methods: historical Original Progression CPFM injection ablation

We evaluated the necessity of the original B14 injection path while retaining the original Progression computation. The original CurrentF16, Original Progression, SD1.5, medical LoRA, VAE and text-encoder weights were frozen. Both arms used identical historical exam sources, query encoding, adjacent-exam delta pooling, 64-dimensional fusion and the 16-dimensional adapted condition. OFF changed only the original B14 enabled gate: the UNet ResNet input was returned without applying the original condition-dependent residual. The condition vector and gamma/beta model outputs were not manually set to zero. No alternative active P16-to-UNet path existed in OFF, so the comparison identifies injection-path dependence, not independent causal effects of P16 and CPFM.

The full historical source/slot/seed lineage recovered 1,545 nodes and 9,270 images across 860 Train patients. The prespecified pilot used the first six stable node keys and all six original seeds. All 36 regenerated ON images exactly matched the decoded historical ON pixels; condition components, prompt embeddings and initial latent tensors were identical between ON and OFF. An independent process replayed six ON and six OFF outputs exactly in latent and RGB space. Route H was therefore fixed before observing any new downstream result. The same original six-image batch, PNDM epsilon scheduler (30 requested steps, 31 actual UNet calls), CFG7, fp16 and RGB512 output were retained; no LoRA scale override was introduced. The exact historical installed-library revision remained unknown, despite the measured pilot parity.

OFF was trained with the original K6 CLIMATv2 protocol using three independent model seeds (42, 3407, 2026), the same 860 Train patients and the same 189 internal-Val patients (131 negative, 58 positive). Real views, causal LOCF, slot masks and Val inputs were unchanged; only predeclared synthetic Train slots used the new OFF images. ResNet18 used the original local official ImageNet initialization; preprocessing, FP32 AdamW, batch4 with accumulation2, loss, schedule and checkpoint selection rules were unchanged. Each new selected-best model underwent strict independent-process reload and full-Val probability comparison. The original ON selected checkpoints and previously verified patient probabilities were retained.

The primary ensemble averaged three positive-class probabilities within each patient. ROC-AUC and average precision were computed on the same 189 patients. Each arm used its historical Youden-J threshold, selecting the smallest threshold on ties; this was not an F1 tuning step. Paired ON-minus-OFF ROC-AUC/AP intervals used 2,000 stratified patient resamples (seed20261012), drawing 131 negative and 58 positive observations and applying the same indexes to both arms. These percentile95% intervals describe reused internal Val, which also informed checkpoint and threshold selection. They are not independent clinical-validation intervals. Medical expert review and Official Test access were not performed. Image-level numerical differences do not establish anatomical or progression realism.
