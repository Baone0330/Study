# 讨论与局限性草稿

历史六分支结果中，Original Progression在ROC-AUC和AP上的排序最高，表明加入原差分表征及替换式融合的生成路线与下游内部Val表现改善相伴。这一观察与“历史变化可为生成条件提供补充信息”的假设相容，但不足以证明疾病进展被准确编码或P16具有独立因果作用。Progression路线同时改变了融合结构、参数量及监督，与Full并非仅增加一个等价维度的条件项。

Plain-SD高于Full是重要的竞争性解释，而不是应被隐藏的异常。通用扩散生成、合成曝光策略、生成分布和下游选模可能共同影响内部Val结果；这些因素在当前比较中未被单独识别。history_only较高Sensitivity与temporal_only较高Specificity也说明，不同条件路线和原阈值选择改变了错误类型的权衡。不能仅从这些结果断言额外条件在所有数据条件下都有利。

该评估使用历史内部Val189人，并沿用旧selected-best checkpoint与原Val阈值规则。内部验证集参与历史选模/阈值选择；部分上游资产的历史拟合范围也不能因重放成功自动认证为完全独立。六位指标匹配只证明计算可重复，不建立端到端无泄露、严格未来影像预测、外部临床效力或部署适用性。本轮不启动新的泄露审计，也不把封存工作称为再次验证这些性质。

模型结构说明亦有具体边界。F16是基于灰度统计的轻量MLP，而非专门学习病理语义的深层视觉编码；Original P16监督来自冻结条件空间的下一历史检查，不是独立医学病程标签。B14具备源码层面的零条件恒等机制，但恒等性不是临床真实性的保证。本轮没有新增医学影像视觉审查或生成质量实验；LoRA完整层级、预训练来源和原生成时库提交也未全面恢复。

后来CleanF16、Clean P16、own-fit B14及Strict Pre-Target协议与本表不是相同研究条件。其已存在的结果应在论文中按实际身份分别陈述，不能并入历史ensemble，也不能声称未开展过其它敏感性分析。本任务完成的是版本封存、模型来源核验和论文展示，而非性能选择或新主实验。

假设/缺项清单：进展补充信息是未证实机制假设；统计CI/p值未新增；外部临床泛化未证明；历史生成库精确revision未恢复；医学图像真实感未在此轮评估。文字将这些缺项直接保留，而非用泛化结论填补。
