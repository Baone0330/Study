# Descriptive integration / 描述性整合

The pre-existing CLIMATv2 fixedK6 historical reference reports REAL ensemble AUC0.763885 and OP AUC0.871808 (difference0.107923). These values were retrieved from the frozen historical reference table, not rerun here. CLIMAT used full9,270 historical synthetic images, whereas LTSA V3/V4/V5 use686 bounded nodes/4,116 images and complete native REAL Exams. Predictor, image organization and synthetic exposure are not input-equivalent.
